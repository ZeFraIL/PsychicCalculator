# 📌 توثيق المحركات والفئات المساعدة (باللغة العربية)

1. **`PsychicEngine.java`**: محرك تنبؤ الأنماط والتكرار وتوقع الأزرار التالية.
2. **`MysticalAiEngine.java`**: ردود الذكاء الاصطناعي الفكاهية عند القسمة على 0 أو النفقات.
3. **`SituationalContextEngine.java`**: تحليل الضوء والبطارية والأوقات الخاصة (الساعة 3 فجراً، الجمعة 13).
4. **`TarotDeck.java`**: إدارة 8 بطاقات تاروت مع الأسماء والرموز والتوجيهات بلغتين.
5. **`AstralVoice.java`**: محرك تحويل النص إلى كلام (نغمة 0.42، سرعة 0.60) للهمس السحري.
6. **`MysticalAudioEngine.java`**: توليد أصوات PCM في الوقت الفعلي (عويل الأرواح، رنين أجراس السحر).
7. **`EyeTrackingAnalyzer.java`**: تحليل الكاميرا بواسطة ML Kit Face Detection وتحديد أرباع الشاشة.
8. **`ParticleSparkView.java`**: طبقة رسم الشرارات والجزيئات المتحركة.
9. **`HapticPulseEngine.java`**: محرك اهتزاز نبضات القلب والتغذية الراجعة.
