# Результаты реализации SplashActivity и LanguageActivity

Все компоненты стартовых экранов приложения успешно разработаны, добавлены в манифест и проверены.

## Реализованные элементы:

1. **`SplashActivity.java` & `activity_splash.xml` (Стартовый экран):**
   - Главная стартовая активность приложения (`LAUNCHER`).
   - Изображение `main_image` увеличивается из точки (`scaleX/scaleY 0 -> 1.0`) за **4 секунды (4000 мс)** с плавным проявлением `alpha`.
   - Заголовок приложения стилизован эзотерическим шрифтом `serif`.
   - По завершении 4 секунд автоматический переход в `LanguageActivity`.

2. **`LanguageActivity.java` & `activity_language.xml` (Выбор языка):**
   - Выбор между `🇬🇧 English` и `🇷🇺 Русский`.
   - При первом запуске по умолчанию активен `English`.
   - Сохранение выбранного языка в `SharedPreferences` (`PsychicPrefs`).
   - Жутковатый **5-секундный обратный отсчет** (`🔮 05`, `⚡ 04`, `👁️ 03`, `👻 02`, `🔥 01`) с анимированной пульсацией шрифта и вибрацией на каждом тике.
   - По нажатию кнопки или завершению 5 секунд происходит сохранение локали и переход в `MainActivity`.

3. **Обновление `AndroidManifest.xml` & `MainActivity.java`:**
   - Настроена иерархия вызова активностей: `SplashActivity` ➔ `LanguageActivity` ➔ `MainActivity`.
   - `MainActivity` зачитывает сохранённый выбор языка при запуске.

## Результат проверки
- Проект успешно собран с помощью команды `:app:assembleDebug`.
